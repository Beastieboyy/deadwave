# Deadwave

A browser-based bullet-heaven survival game built with [Phaser.js](https://phaser.io/).

Survive endless waves of the undead, collect power-ups, and rack up the highest score you can.

## Play

Open `deadwave.html` in any modern browser — no server required.

## Tech

- **Engine:** Phaser.js
- **Language:** JavaScript
- **Deployment:** Single HTML file, zero dependencies
